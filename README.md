# Стартовий шаблон курсу «Агентна інженерія»

Каркас репозиторію для лабораторних робіт дисципліни **«Агентна інженерія та побудова систем з ШІ-агентами»** — IT STEP University, спеціальність 122, 2026/2027.

Цей репозиторій ви створюєте **один раз** і працюєте в ньому **весь семестр**: він починається як порожній каркас, а до четвертої лабораторної виростає у харнес із субагентами, специфікаціями, верифікатором і брамами якості.

Слайди курсу: <https://koldovsky.github.io/2026-2027-agentic-engineering-course/>

## Швидкий старт

1. Натисніть **«Use this template» → Create a new repository**. Не форкайте: вам потрібна власна історія комітів, бо порядок ваших комітів — частина доказів.
2. Далі в терміналі:

```bash
git clone https://github.com/<ваш-логін>/<ваш-репозиторій>.git
cd <ваш-репозиторій>
npm install
npm run doctor
```

3. `npm run doctor` надрукує таблицю `OK / FIX`. Доведіть її до стану без жодного `FIX` в обов'язкових пунктах **до першого заняття** і надішліть скріншот викладачу.
4. Скопіюйте `.env.example` у `.env.local` і заповніть ті ключі, які у вас є. Порожні рядки — нормально: жодна лабораторна не вимагає платної підписки.

```bash
cp .env.example .env.local
```

## Що вже є, а що будуєте ви

Шаблон навмисно мінімальний. Усе, що є **навчальним артефактом**, ви створюєте самі — інакше лабораторна втрачає сенс.

| Дано в шаблоні | Створюєте ви |
|---|---|
| Каркас застосунку, строгий TypeScript, тести, лінтер | Ендпоінт `/api/health` — перша задача, яку ви делегуєте агенту |
| Мінімальний CI, зелений на першому коміті | Повноцінні брами якості (заняття 5) |
| `src/models.ts` — реєстр моделей за ролями | Звірка цін і дат з актуальними сторінками вендорів |
| `.env.example` | `.env.local` зі своїми ключами |

| Каркас `AGENTS.md` із маркерами TODO | Власний `AGENTS.md` — **єдиний файл курсу, який заборонено генерувати агентом** |
| `.claude/settings.example.json` — приклад hooks | Робочий `.claude/settings.json`: журнал і заборони |
| Пояснення, як влаштовані навички | Власну навичку `SKILL.md` (заняття 3) |

## Лабораторна 1 — календар

Одна лабораторна на чотири тижні, приблизно 18 годин самостійної роботи. Кожне заняття додає один шар.

| Заняття | Що з'являється в репозиторії |
|---|---|
| 02 | `AGENTS.md`, hook-журнал, перші записи в `.agent-log/` |
| 03 | Навичка, заборони на захищені шляхи, скріншот-тест як доказ |
| 04 | Власний агентний цикл, `cost.ts`, мінімальний деплой із трасами |
| 05 | **Подання пакета доказів до початку заняття**, усний захист |

Повні критерії прийняття — у слайдах заняття 02 і в методичних вказівках.

## Чому не найновіші версії

Свідомі пониження. Кожне перевірено емпірично — з найновішими версіями репозиторій не збирається.

- **TypeScript 6, не 7.** Пакет `typescript-eslint` усередині конфігурації Next поки що не підтримує сьому версію і зупиняє лінтер помилкою ще до перевірки коду. Усі суворі прапорці, яких вимагає курс (`strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`, `exactOptionalPropertyTypes`), у шостій версії є.
- **ESLint 9, не 10.** `eslint-plugin-react` падає на десятій версії. Під час встановлення npm друкує попередження, що дев'ята більше не підтримується — воно косметичне, лінтер працює.
- **`@types/node` 24** — відповідає версії Node, на якій працює CI.

Це саме той клас рішень, який ви документуватимете у власних проєктах: не «взяли найсвіжіше», а «взяли те, що працює разом, і записали чому».

## Журнал дій агента

Тека `.agent-log/` **комітиться разом із кодом** — це ваш пакет доказів. Журнал наповнює hook, який ви налаштуєте на першому занятті; приклад конфігурації лежить у `.claude/settings.example.json`.

Якщо ваш інструмент не має зручних hooks, використайте конвертер транскрипту:

```bash
npm run log:import -- --in <шлях-до-транскрипту> --source auto
```

Формат один для всіх інструментів навмисно: саме він дозволяє порівняти два інструменти між собою, а це вимога лабораторної.

**Редагування журналу заднім числом — академічна недоброчесність**, і оцінюється як нуль за роботу. Незручний запис у журналі коштує менше, ніж підчищений.

## Політика даних

Умови безкоштовних рівнів більшості провайдерів дозволяють використовувати ваші запити для навчання моделей. Тому:

- через безкоштовні рівні проходить **лише ваш власний навчальний код** і публічні матеріали;
- код одногрупника, чужі репозиторії та будь-які чутливі дані — **тільки через локальну модель** або ключ із вимкненим навчанням.

Через це профіль `local` у `src/models.ts` обов'язковий у кожному репозиторії курсу з першого тижня, а не з четвертої лабораторної, коли він знадобиться вперше.

## Використання ШІ

Дисципліна присвячена роботі з агентами, тому користуватися ними не просто дозволено, а необхідно. Умови незмінні протягом усього курсу:

- ви розумієте і можете пояснити **кожен рядок** поданого рішення;
- інструменти, якими ви користувалися, зазначені в журналі автономності;
- згенерований вміст перевірено на коректність, безпечність і ліцензійну чистоту.

Подання матеріалу, який ви не можете пояснити на захисті, розцінюється як академічна недоброчесність — незалежно від того, хто його написав.
