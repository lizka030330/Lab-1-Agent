
# Переносність між інструментами — Лабораторна 1

| Артефакт | OpenCode | Codex |
|---|---|---|
| AGENTS.md | Працює без змін: OpenCode читає `AGENTS.md` у корені репозиторію і дотримується правил про перевірки, межі та дозволи. | Працює без змін: Codex також використовує `AGENTS.md` у корені репозиторію як інструкції для роботи з проєктом. |
| Режим плану | Потрібна адаптація: режим Plan вмикається клавішею `Tab`. У Plan агент лише аналізує і пропонує план. Для реалізації після схвалення потрібно перейти в Build. | Потрібна адаптація: режим Plan вмикається через `/plan`. Після перегляду плану можна вибрати `Yes, implement this plan`, після чого Codex переходить у звичайний режим і виконує зміни. |
| Журнал | Потрібна окрема реалізація через `.opencode/plugins/agent-log.js`. Події записуються у `.agent-log/opencode.jsonl`. У журналі видно виклики інструментів, зокрема `skill`, команди та інші дії агента. | Потрібна окрема реалізація через `.codex/hooks.json` і `scripts/agent-log-hook.mjs`. Події записуються у `.agent-log/codex.jsonl`. Для Codex виклик навички підтверджується читанням відповідного `SKILL.md` у журналі. |
| Навичка | OpenCode читає навичку безпосередньо з `.claude/skills/` (також підтримує `.agents/skills/`). Автоматично викликає `add-api-route` для задач зі створення API-маршрутів. У тесті 3/3 позитивних запитів викликали навичку, а 3/3 негативних запитів про сторінки, компоненти та стилі — не викликали її. | Потребує синхронізації навички в `.agents/skills/` через `npm run sync-skills`. Codex бачить `add-api-route` у `/skills` і для API-задач читає `add-api-route/SKILL.md`. У тесті 3/3 позитивних запитів активували навичку, а 3/3 негативних — ні. |
| Заборона | Реалізовано через permission-маски в `opencode.json` та плагін `.opencode/plugins/guard-env.js` (`tool.execute.before`). Плагін блокує доступ до `.env` і записує `result: "denied"` у `.agent-log/opencode.jsonl`. Перевірено блокування shell-переадресації, команди `node -e` та читання `.env` інструментом `read`. Після виправлення плагіна додатково перевірено блокування тестової команди без її фактичного виконання. Прямий запис через `edit` окремо не підтверджено. | Спробували реалізувати через `PreToolUse` у `.codex/hooks.json`, але під час практичної перевірки блокування не спрацювало. Експериментальну конфігурацію прибрано, попередній `PostToolUse` для журналювання відновлено. Додатковий захист у Codex потребує доопрацювання. |
| MCP | Context7 підключено через `opencode.json` без API-ключа. Реальні виклики `context7_resolve-library-id` і `context7_query-docs` підтверджено журналом. Розмір відповідей становив 2046 і 3299 символів відповідно (разом 5345). | Context7 підключено глобально через `~/.codex/config.toml` з авторизацією OAuth. У журналі підтверджено успішні виклики `mcp__context7__resolve_library_id` і `mcp__context7__query_docs`. Точну ціну в токенах не виміряно. |
| Скріншот-тест | Крок 06 — ще не виконано. | Крок 06 — ще не виконано. |
