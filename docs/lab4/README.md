## 4. Як повторити мій прогін
⏳ Текст, перевірений партнеркою на кроці 08 (`repro.md`). Чернетка:
1. Node ≥ 22.12 (у мене 24.21.0), OpenCode 1.19.6, Ollama з моделлю `qwen3-8b-16k` (`ollama create qwen3-8b-16k -f scripts/harness/Modelfile`), **свій** ключ Gemini з AI Studio.
