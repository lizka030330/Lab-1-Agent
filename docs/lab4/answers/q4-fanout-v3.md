# q4: Як compile() реагує на відсутній обовʼязковий параметр і на відсутній параметр усередині необовʼязкової групи {…}? Де це в коді й у тестах?

Функція compile() по-різному обробляє відсутність обов'язкових параметрів та параметрів усередині необов'язкових груп {…}. Якщо обов'язковий параметр (звичайний або wildcard) має значення null або undefined, його назва записується у масив missing. Наприкінці виконання скомпільованої функції перевіряється довжина масиву missing, і якщо вона більша за нуль, викидається виняток TypeError з переліком відсутніх параметрів. Для необов'язкової групи ({…}) перед обробкою токенів запам'ятовується поточна довжина масиву missing. Якщо всередині групи будь-який параметр виявився відсутнім, масив missing скидається назад до початкової довжини, а сама група повертає порожній рядок. Завдяки такому відкату відсутність параметра всередині необов'язкової групи не призводить до викидання винятку. У коді обробка помилок та скидання missing реалізовані у файлі src/index.ts. У тестах перевірка винятку для обов'язкових параметрів знаходиться в блоці compile errors файлу src/index.spec.ts. Тестування необов'язкових груп здійснюється через параметризований набір тестів COMPILE_TESTS у src/index.spec.ts.

- c2: Якщо після обробки параметрів масив missing містить елементи, compile() викидає TypeError з повідомленням Missing parameters. — `src/index.ts#L269-L271`
- c3: Для необов'язкової групи перед генерацією вкладених токенів зберігається початковий розмір масиву missing. — `src/index.ts#L319`
- c4: Якщо в необов'язковій групі параметр відсутній, розмір missing повертається до збереженого значення, а група повертає порожній рядок. — `src/index.ts#L321-L325`
