# q3: Які символи parse() не дозволяє в шаблоні без екранування, який клас помилки кидається і де це перевіряють тести?

Функція parse() не дозволяє використовувати в шаблоні без екранування набір спеціальних символів: }, (, ), [, ], +, ? та !. Крім того, забороненим є символ зворотного слеша \, якщо він знаходиться в самому кінці рядка або групи без наступного символу для екранування. Також неприпустимими без коректного імені чи закритих лапок є символи префіксів параметрів : та *. При виявленні заборонених символів генерується помилка власного класу PathError. Цей клас у коді бібліотеки безпосередньо успадковується від стандартного класу TypeError. Перевірка некоректних шаблонів та помилок розбору виконується у тестовому файлі src/index.spec.ts у блоці describe("parse errors"). Зокрема, заборонені спецсимволи перевіряються параметризованим набором тестів it.each для рядків вигляду /foo/${char}. У цих тестах очікується викидання PathError із повідомленням про неочікуваний символ на відповідній позиції.
