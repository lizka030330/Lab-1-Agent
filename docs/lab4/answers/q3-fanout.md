# q3: Які символи parse() не дозволяє в шаблоні без екранування, який клас помилки кидається і де це перевіряють тести?

Під час синтаксичного аналізу шаблону функція parse() явно забороняє використовувати без екранування символи }, (, ), [, ], +, ? та !. Крім цього, неприпустимим є символ зворотного слеша \, якщо він зустрічається наприкінці рядка без символу, який екранується. Також не дозволяється залишати незакритими лапки в іменах параметрів або дужку { для блоків, а префікси : та * вимагають обов'язкового імені. У разі виявлення будь-яких некоректних символів чи синтаксичних порушень викидається виняток класу PathError, який успадковує стандартний TypeError. До повідомлення про помилку клас PathError додає оригінальний рядок шляху та посилання на відповідну документацію. Усі ці перевірки покриваються тестами в блоці describe("parse errors", ...) у тестовому файлі. Зокрема, окремий тест перевіряє викидання помилки для списку заборонених символів }, (, ), [, ], +, ? та !. Тести також окремо валідують висячі бекслеші, незакриті дужки та відсутні ідентифікатори параметрів.
