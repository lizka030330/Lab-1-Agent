# q4: Як compile() реагує на відсутній обовʼязковий параметр і на відсутній параметр усередині необовʼязкової групи {…}? Де це в коді й у тестах?

У функції compile() обробка відсутніх параметрів побудована навколо службового списку missing. Коли значення звичайного параметра відсутнє або дорівнює null чи undefined, його ім'я записується в масив missing, а сам токен повертає порожній рядок. Наприкінці роботи згенерованої функції здійснюється перевірка довжини цього масиву. Якщо missing містить хоча б один елемент, compile() викидає виняток TypeError із повідомленням про відсутні параметри. Зовсім інакше обробляються токени типу group, які відповідають синтаксису необов'язкової групи {...}. Перед формуванням вмісту групи запам'ятовується поточна довжина списку missing. Якщо всередині групи виявляється відсутній параметр, масив missing скидається до початкової довжини, запобігаючи генерації помилки. У результаті вся необов'язкова група цілком рендериться як порожній рядок. У тестах таку поведінку перевіряє блок compile errors, що очікує виняток для відсутніх обов'язкових параметрів. Натомість для шляхів на кшталт {/:test} тести підтверджують успішне повернення порожнього рядка без помилок.
