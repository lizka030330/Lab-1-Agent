## 4. Як повторити автономний прогін

1. Підготовка: Node ≥ 22.13, `npm ci`; OpenCode 1.18.34 (`npm install -g opencode-ai@1.18.34`); у `.env` — `GOOGLE_GENERATIVE_AI_API_KEY` (імена змінних — у [.env.example](https://github.com/lizka030330/Lab-1-Agent/blob/5a6408981b227838a40e8bf78cf0f3e5b72f5056/.env.example)). Для судді — `ollama pull qwen3:8b && ollama create qwen3-8b-16k -f scripts/harness/Modelfile`. Для трас — `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_EXPORTER_OTLP_HEADERS` у середовищі (див. [errors.md](https://github.com/lizka030330/Lab-1-Agent/blob/5a6408981b227838a40e8bf78cf0f3e5b72f5056/docs/lab3/errors.md)).
2. Одна задача: `npx tsx scripts/harness/run-queue.ts docs/lab3/tasks.jsonl --id t-08 --no-push`; уся черга — без `--id`. Артефакт — `docs/lab3/runs/<id>-<мітка>/` (`run.json` з `trace_id`, `patch.diff`, `output.txt`). Верифікатор: `npm run verify:harness -- docs/lab3/runs/<id>-<мітка>`. Evals: `npx tsx scripts/evals/run-evals.ts docs/lab3/tasks.jsonl`. Red-team: `npx tsx scripts/redteam/run-redteam.ts`.
3. Режим дозволів і перелік дозволених інструментів: OpenCode **без `--auto`** (`opencode run … --agent harness`), перелік — [.opencode/agents/harness.md](https://github.com/lizka030330/Lab-1-Agent/blob/5a6408981b227838a40e8bf78cf0f3e5b72f5056/.opencode/agents/harness.md): `edit` дозволено, крім `opencode.json`, `.opencode/**`, `.github/**`, `AGENTS.md`; `bash` — `"*": deny` і лише `npm test*`, `npm run typecheck*`, `npm run lint*`, `git diff*`, `git status*`; `external_directory`, `webfetch` — deny; сервери MCP вимкнені; `steps: 20`. Глобально в [opencode.json](https://github.com/lizka030330/Lab-1-Agent/blob/5a6408981b227838a40e8bf78cf0f3e5b72f5056/opencode.json) `read`/`edit` для `*.env` — deny. Це аналог `dontAsk` + `--allowedTools` з Claude Code.
4. Спосіб ізоляції: окремий git worktree на кожну задачу — `git worktree add -b harness/<id>-<мітка> ../harness-runs/<id>-<мітка> HEAD` (робить `run-queue.ts` сам і прибирає після прогону, зокрема по Ctrl+C); для red-team — `../redteam-runs/<id>-<мітка>/w`. Основний checkout перед прогоном має бути чистий — інакше черга відмовляє.
5. Зупинення: таймаут за годинником стіни (`budget.timeout_s` задачі), `steps` агента, зупинка на першій відмові за квотою, circuit breaker зі станом у `.harness/` — [stop.md](https://github.com/lizka030330/Lab-1-Agent/blob/5a6408981b227838a40e8bf78cf0f3e5b72f5056/docs/lab3/stop.md).
